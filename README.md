# SaveTree 🪾
A local save backup utility for games. SaveTree can not only keep a flat list of saves, but also branch into a tree of saves if you prefer such in games with branching narratives; hence the name 'SaveTree'.This let's you jump back to any saves you want and continue a new branch from there without overwriting progressions in other branches.

> ## ⚠️ Work in progress
> This project is still being built and unfinished.

## Build Requirements
- Gradle (>= 9.7.1)
- JDK (>= 25.0.4)
- Enable preview for `javac` & `java`

Although, you can use any Java compiler for this project, the Gradle file is configured to use with GraalVM.
